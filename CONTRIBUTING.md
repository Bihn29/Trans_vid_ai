# Contributing

Read `AGENTS.md` before changing code. Keep each change scoped to one milestone and update its acceptance criteria. Use conventional, imperative commit subjects and explain security-relevant tradeoffs in `docs/decisions/`.

Before requesting review, run `pnpm lint`, `pnpm typecheck`, `pnpm build`, and `pnpm test`. Never suppress a failing check, commit a credential, add an unreviewed binary/model, or introduce a prohibited license. New user-facing text must be Vietnamese and routed through the UI message catalog.
